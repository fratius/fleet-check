# Tessera

Tessera by fontzz (https://fontzz.vercel.app, https://github.com/Luffixos/fontzz), version 1.000, under the SIL Open
Font License 1.1 (OFL.txt). The app uses four of its static weights: Regular, Medium, SemiBold and Bold. The website
uses the variable file (`website/fonts/tessera.woff2`).

**Modified:** Romanian Ș ș Ț ț (U+0218 to U+021B, comma below), which Tessera lacks, were added to these files and
to the website's file by `scripts/tessera-romanian.py` (each one is the letter plus the font's own comma, smaller,
under it). The version string says so. Tessera declares no Reserved Font Name, so the family keeps its name.
