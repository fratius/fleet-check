Fratius for Android

The test version, for the delivery partners trying Fratius before it is in Google Play.

Download for Android

Open this page on the Android phone you want to install Fratius on: fratius.com/android

The test version isn't ready yet. Until then, use the web app in Chrome and add it to the home screen.

Install it

  1. Tap Download for Android. If Chrome warns about the file, tap Download anyway.
  2. Open the downloaded file. The first time, Android asks to allow installing apps from Chrome: tap Settings, turn on Allow from this source, and go back.
  3. Tap Install, then Open, and sign in with your Fratius account.

If Play Protect warns about an unknown app, tap More details, then Install anyway. Fratius isn't in Google Play yet, so Google doesn't know it.

Updates

The app updates itself when it starts. Now and then a new version needs a new download: then the app shows a Download button. Install it over the old one; you stay signed in and nothing waiting to send is lost.

Company phones

Some company phones don't allow apps from outside Google Play. Ask whoever looks after the phones, or use the web app: open it in Chrome and add it to the home screen.
